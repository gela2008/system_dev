# スケジュール管理システム 動作手順書
## システム概要
カレンダー形式で予定やタスクを管理できるWebアプリケーション

## 動作環境
- Windows
- XAMPP
- PHP

## セットアップ手順
1. 本リポジトリを`C:\xampp\htdocs\`配下に配置
2. XAMPPを起動し、Apacheを開始
3. 必要に応じてデータベースを初期化
4. ブラウザで`http://localhost/system_dev/`にアクセス
5. ログイン後、カレンダー上でスケジュール・タスクの管理を行う

## 操作手順
### ログイン
1. ユーザ名、パスワードを入力し、ログインを押す

### 追加
1. カレンダーから日付（スケジュール：当日、タスク：締切）を選択
2. 詳細画面下部の追加を押す
3. スケジュール・タスクのいずれかを選択し、詳細を入力して追加を押す
