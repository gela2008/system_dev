## システム概要
カレンダー形式で予定やタスクを管理できるWebアプリケーション

## 動作環境
- Windows
- XAMPP
- PHP

## セットアップ手順
1. 本リポジトリを`C:\xampp\htdocs\`配下に配置
2. XAMPPを起動し、Apacheを開始
3. 必要に応じてデータベースを初期化
4. ブラウザで`http://localhost/system_dev/`にアクセス
5. ログイン後、カレンダー上でスケジュール・タスクの管理を行う

## 操作手順
### ログイン
1. ユーザ名、パスワードを入力し、ログインする

### 追加
1. カレンダーから日付を選択
2. 詳細画面下部の「追加」を押す
3. スケジュール・タスクのいずれかを選択し、詳細を入力して追加

### 削除
1. Todo一覧から削除したいスケジュールまたはタスクを選択
2. 詳細画面から削除

### 編集
1. Todo一覧から編集したいスケジュールまたはタスクを選択
2. 詳細画面で「編集」を押す
3. 内容を変更し保存

### 完了状態の変更
1. タスク一覧の完了済みのタスクにチェックを入れる
2. カレンダー画面のタスクが非表示になる

### お知らせ
1. カレンダー画面のお知らせアイコンを押す
2. 今日・明日の締切や着手予定などのお知らせを確認する

### ログアウト
1. ホーム画面などからログアウトを押す
2. ログイン画面に戻る
